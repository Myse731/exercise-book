# 1차시 : 전기 전자 기초(1)

## 일상속의 암호 같은 숫자들

- AC
    - 시간에 따라 전기의 방향과 크기가 계속해서 바뀌는 전류
    - 전기가 오락가락 움직이는 형태입니다. 콘센트에서 나오는 전기가 바로 AC입니다. 멀리 보낼 때 전력 손실이 적다는 장점이 있습니다.
- Hz
    - 교류(AC) 전기가 **1초 동안 방향을 몇 번 바꾸는지(진동하는지)** 나타내는 단위
    - **쉽게 이해하기:** 한국 표준 전력인 **60Hz**는 전기의 +와 - 방향이 1초에 60번 바뀐다는 뜻
- Dc
    - 시간에 지나도 **전기의 방향과 크기가 일정한 전류**
    - **쉽게 이해하기:** 한쪽 방향으로만 똑바로 흐르는 전기입니다. 건전지, 스마트폰 배터리, 아두이노 보드 등이 DC를 사용합니다.

!image.png

- **`AC 100~240V 50~60Hz 0.3A` (입력):** 전 세계 어디서나(100V~240V, 50/60Hz) 콘센트에 꽂아 쓸 수 있는 프리볼트 어댑터이며, 이때 최대 **0.3A**의 교류 전류를 소비한다는 의미
- **`DC 5.0V 1.55A` (출력):** 어댑터가 기기로 보내주는 전력으로, **5V의 직류(DC)** 전압과 최대 **1.55A**의 전류를 공급
- **`AC 250V ~ 16A (MAX 4000W)`:** 멀티탭이 버틸 수 있는 **최대 안전 한도**
    - 최대 **250V** 교류 전압 및 **16A** 전류까지 사용 가능하며, 연결된 가전제품들의 총 소비전력 합계가 4000W(와트)를 넘지 않아야 안전하다

## 전기의 세계를 이해하는 4가지 언어

!image.png

- 전압 (V, V) → 기호, 단위
    - 밀어주는 힘
    - 전압은 물탱크의 높이(수압)와 같다.
    - 220v는 110v보다 2배 더 높은곳에서 전기를 강하게 밀터붙인다.
- 전류 (I, A)
    - 흐름의 양
    - 전류는 파이프를 통과하는 물의 흐름이다
    - 전압(압력)이 강할수록 더 많은 전기가 콸콸 쏟아져 지나간다
- 전력 (P, W)
    - 실제 하는 일
- 저항 (R, Ω)
    - 병목현상으로 흐름제어
    - 저항은 파이프의 막힘 정도
    - 전기가 너무 많이 흐르지 않도록 방해하고 조절하여 기기를 안전하게 지켜준다
    - 전선의 굵기가 얇거나 길이가 길어지면 저항이 커진다
    - 저항은 전류의 흐름을 방해(통제)하며, 이 과정에서 에너지는 열로 변환

## 전력의 통제(수력 예시)

#### “ 흐름의 규모가 곧 만들어내는 물리적 ‘힘(일)’의 크기를 결정한다”

- 작은 흐름 = 작은 에너지
- 통제된 거대한 흐름 = 산업의 동력
- 통제 불능의 흐름 = 파괴적 재난

> 수력 에너지의 크기는 떨어지는 물의 양과 높이에 비례한다
> 

!image.png

- 상황에 따라 전압, 전류, 저항 중 아는 값 2개만 있으면 전력을 계산할 수 있다
- 전력의 값이 크다는 것은 더 큰 힘을 내고 더 많은 일을 할 수 있다는 뜻이다
- 동시에 더 많은 전류를 소모한다

## 거대한 로봇의 통제

#### “거대한 로봇을 움직이기 위해 전력(P)을 키우려면, V, I, R 값을 어떻게 세팅해야 할까?”

- 전압이 통제(고정)된 시스템
    - 전압이 일정한 상태에서는 ‘저항을 감소’시켜야 전력이 커진다
    - (전류가 증가하기 때문)
- 전류가 통제(고정)된 시스템
    - 강제로 일저한 전류가 흐르는 상태에서는 ‘저항을 증가’시켜야 전력이 커진다
    - (더 강한 전압이 필요하기 때문)
- 저항이 통제(고정)된 시스템
    - 로봇 부품이 정해져있다면 공급하는 ‘전류나 전압을 증가’ 시키면 된다

## 사용 도구들

### 도화지 : 브레드 보드(Breadboard)

- 납땜없이 회로를 스케치하고 수정할수있는 메이커의 캔버스
- 전원 라인은 가로로 길게 연결된다
- 중앙 홈을 기준으로는 서로 끊어져 있다
- 부품라인은 세로로 5칸씩만 연결된다
- 부품의 두 다리를 같은 세로줄(단자띠)에 꽂으면 부품이 아닌 전선으로 전기가 흐릅니다. 반드시 다른 줄에 꽂아주세요
- Tip : 선 색상 규칙 - 전원(+)은 빨간색, 접지(GND)는 검은색을 사용하면 디버깅이 10배 더 쉬워진다

### 진단기 : 멀티미터(Multimeter)

- 보이지 않는 전기의 흐름(V, I, R)을 수치로 보여주는 현미경
1. 디스플레이 : 측정값이 숫자로 표시되는 창
2. 로터리 스위치(다이얼) : 전압, 전류, 저항 선택
    1. 직선 기호는 DC 직류, 물결 기호는 AC 교류를 의미
3. 하단 포트 : COM(검은색), 볼트/저항(빨간색), 10A/mA(빨간색 고전류용) 세가지 구멍

> 프로브 연결의 절대 공식
> 
- 검은색은 언제나 COM, 빨간색 리드의 위치만 바뀐다
- step1 : 불변의 법칙
    - 검은색 프로브는 무조건 COM 포트에 고정
- step2 : 목적에 따른 이동
    - 빨간색 프로브는 측정대상에 따라 이동
    - 일반적인 측정은 우측 포트
    - 아주 큰 전류 측정시에만 좌측 포트 사용

> 멀티미터 마스터 치트 시트
> 

| 구분 | 전압(V) | 전류(A) | 저항(Ω) |
| --- | --- | --- | --- |
| 측정 개념 | 양단 전위차 | 흐르는 전하량 | 전류 방해 정도 |
| 연결 방식 | 병렬(회로 덧댐) | 직력(회로 끊고 삽입) | 부품 관리 |
| 전원 상태 | 반드시 ON | 반드시 ON | 반드시 OFF |
| 로터리 세팅 | V(직류/교류) | mA 또는 A | Ω |
| 빨간 포트 | V/Ω | mA 또는 10A | V/Ω |

#### 직렬 회로의 3대 특성

## 병렬회로란 ?(Parallel Circuit)

#### “부품들이 여러 경로로 분기되어 각각 같은 전압을 받는 회로”

!image.png

#### 병렬 회로의 3대 특성

- 전압은 일정하고 전류는 분배되며, 전체 저항은 오히려 감소한다
- V total = V 1 = V 2 = V 3
    - 전압 : 모든 경로에서 동일
- I total = I 1 + I 2 + I 3
    - 전류 : 갈래길로 나뉘어 흐름
- 1 / R total = 1 / R 1 + 1 / R 2 + 1 / R 3
    - 저항 : 통로가 많아져 전체 저항 감소

- 단위는 F, 숫자 직인 또는 색 코드로 용량(pF, nF, uF)과 정격 전압 표시

> **콘덴서**
> 
- 전기를 일시적으로 저장했다가 방출하거나, 직류를 차단하고 교류를 통과시키는 전자 부품
- 주요기능
    - 전압안정화(평활)
    - 노이즈 제거(바이패스)

- 직류 차단/ 교류 통과(신호 필터 역할)

> **인덕터**
> 
- 전압이 연결될때 전류 흐름에 반대되는 방향의 유도기전력(역기 전력)을 발생시켜 전류가 급격히 변하는 것을 방지하는 소자
- 단위는 H(헨리), 3자리 숫자, 2자리 +. ㅜㄴ자, 3자리 + 알파벳, 또는 색상 코드로 읽는다
- 주요기능
    - 전류 변화 억제
    - 전압 변환
    - 필터링 및 노이즈 제거
    - 전력 공급 안정화

## 반도체

- 도체 : 전류 통과(ON)
    - 전기가 아주 잘 흐르는 물질
- 부도체 : 전류 차단(OFF)
    - 전기가 흐르지 못하는 물질
- 반도체 : 전류가 흐를까? 막힐까?
    - 조건에 따라 성질이 변하는 마법의 물질

> **반도체(Semiconductor) 란 무엇인가?**
> 
1. 평소 상태(순수 상태)
    1. 순수한 상태에서는 전기가 통하지 않는 부도체처럼 작동
2. 조건제어(도핑, Doping)
    1. 빛이나 열을 가하거나, 특정 불순물을 섞는 도핑과정을 거치면 전기가 흐르게 된다
3. 스위치 역할
    1. 전기의 흐름을 필요에 따라 켜고(ON) 끄고(OFF) 스위치 처럼 전류를 능동적으로 제어 한다

> **N형 반도체(음의 불순물)**
> 

!image.png

- 정의 : 5가 원소(P, As)를 도핑한 반도체
- 자유 전자 생성 : 공유 결합 후 남은 여분의 전자가 원자 사이를 자유롭게 이동하며 전기를 통하게 함
- 주요 캐리어 : 전자(음의 전하)
- 기호 : N(Negative)

> P형 반도체(양의 불순물)
> 
- 정의 : 3가 원소(B, Ga)를 도핑한 반도체
- 정공 생성 : 전자가 부족하여 전자가 이동할수있는 빈자리인 정공(Hole) 발생
- 주요 캐리어 : 정공(양의 전하)
- 기호 : P(Positive)

## LED

LED(Light Emitting Diode, 발광 다이오드)

!image.png

- 정의
    - 전류가 흐를때 빛을 방출하는 특수 다이오드
    - 기본 원리 : P-N 접합부에서 전자와 정공이 재결합할때 발생하는 에너지 활용
    - 특징 : 백열등처럼 열을 내는 방식이 아닌, 빛의 형태로 에너지를 직접 방출하여 효율이 극도로 높음
- 순방향 강하 전압(Vf) : 약 1.8V ~ 2.1V(빛의 색상별로 상이함)
- 구동 정격 전류(lf) : 수 mA ~ 20mA
    - 이 전류를 초과하면 LED 파손 위험 있음

    - 학생들의 용돈으로도 부담없이 구매 가능한 접근성
- 무한한 확장성
    - 다양한 센서와 액추에이터를 연결해 나만의 아이디어를 현실로 구현

> **활용사례**
> 
- 스마트팜 : 온습도 자동 조절 및 토양 수분 측정
- 모빌리티 : 장애물 회피 로봇 및 RC 카
- 미디어 아트 : 센서에 반응하는 웨어러블 LED 의상
- 사물인터넷 : 날씨 정보 출력 e-ink 디스플레이
- 자동화 : 정해진 시간에 작동하는 반려동물 급식기

> 아두이노 UNO 구성 요소
> 
- 마이크로컨트롤러 : 아두이노의 ‘두뇌’(디지털 신호 연산 및 전체 제어 담당)
- USB 포트 : 컴퓨터와 대화하고 전기를 먹는 ‘입’(코드 업로드 및 전원 공급)
- 전원 커넥터 : 외부 배터리나 어댑터로 독립적인 전원을 공급
- 리셋 버튼 : 프로그램을 처음 부터 다시 시작할때 누르는 버튼
- 상태 LED : 통신 상태(데이터 송수신)를 시간적으로 보여주는 ‘표정’
- 핀 헤더 : 외부 센서를 느끼고 모터를 움직이는 ‘손과 발’

> 아두이노 - 전원 핀
> 
- 5V & 3.3V
    - 외부 센서와 부품에 심장처럼 작동 전압을 뿜어내는 출력핀
- GND(Ground)
    - 전류가 모든 일을 마치고 돌아오는 기준점(0V). 회로를 완성하는 가장 필수적인 요소
- Vin(Voltage In)
    - 외부전원(배터리 등)을 아두이노로 직접 입력할 때 사용하는 핀

> 아두이노 - 디지털 핀
> 
- 핵심 개념 : 총 14개
    - ‘모아니면 도’인 1(HIGH/5V) 과 0(LOW/0V)의 이산적인 신호만 처리
- 입출력 모드 : 센서 입력(버튼 읽기) 또는 출력(LED 켜기)으로 자유롭게 설정 가능
- 특수 기능(PWM~): 번호 앞에 물결 표시가 있는 6개의 핀. 아날로그 처럼 밝기 조절등을 흉내냄
- 특수 기능(TX/RX) : 0번과 1번은 PC와의 통신 통로이므로 일반 부품 연결 자제

> 아두이노 - 아날로그 핀
> 
- 핵심 개념 : 총 6개
    - 빛의 밝기, 온도, 소리의 크기처럼 ‘연속적으로 변하는’ 현실 세계의 자연 물리량을 읽어 들임
- ADC
    - 역할 : 외국인(아두이노)에게 자연언어를 숫자로 번역해주는 통역사
    - 스펙 : 현실의 아날로그 전압(0V ~ 5V)을 아두이노가 이해할수있는 디지털 수치 0 ~ 1023(총 1024단계)로 정밀하게 변환
- 사용 목적
    - 정밀한 값을 측정해야하는 다양한 아날로그 센서들을 연결하는 입력 전용 창구

```arduino
void setup(){ -> setup()함수는 프로그램 시작시 1번 실행
```

## 시리얼 통신

!image.png

- 컴퓨터와 아두이노 보드 사이에 데이터를 주고 받는 통신
- 한번에 1비트씩 순차적으로 데이터 전송
- USB 케이블을 통해 물리적으로 연결
- 주로 디버깅, 센서 데이터 수집, 명령 전송에 사용

> **시리얼 통신으로 데이터를 보내보자**
> 

```arduino
void setup(){
	Serial.begin(9600); -> 통신 속도 9600bps로 설정
}

void loop(){
	Serial.print("Hello Arduino"); -> 줄바꿈 없이 출력 (줄바꿈 : println)
	delay(1000);
}
```

- 컴퓨터와 보드가 같은 속도로 설정해야 대화가 가능하다
- Baud Rate란?
    - 초당 몇개의 비트를 전송하는가를 나타냄
    - 단위 : bps(bits per second)
    - 예 : 9600, 19200, 115200 등
- value : 출력할 데이터(숫자, 문자, 문자열)
- format : 형식(선택사항)

> **시리얼 통신 함수**
>

```arduino
Serial.available() > 0 -> 우체통에 편지가 있는가?

- 데이터가 없으면 0 반환

Serail.read() -> 가장 오래된 편지 1통을 꺼내서 읽는다
- 데이터중 앞에서부터 하나를 읽어 값을 반환
```
