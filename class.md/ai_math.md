# **1차시**

## 스칼라, 벡터, 행렬

### “현실의 데이터와 신경망의 계산을 숫자로 표현, 그 숫자들을 효율적으로 계산하기 위해서 필요하다.”

- 개념
    - Ai에서 하는 역할
- 스칼라
    - 하나의 값을 나타낼때 사용
- 벡터
    - 데이터를 여러 숫자를 한꺼번에 표현
    - 숫자를 여러개로 묶은 것
    - Ai에서는 특히 데이터의 특징, 단어의 의미를 표현할때 중요
    - 현실의 복잡한 정보를 숫자 여러개로 바꿔놓은것
- 행렬
    - 벡터를 변환하는 강력한 도구
    - 숫자를 가로 x 세로로 묶은 것
    - AI에서 행렬이 중요한 이유는 신경망의 계산 대부분이 행렬 연산으로 이루어지기 때문
- 텐서
    - 행렬을 여러 차원으로 확장
- Ai는 왜 행렬을 계속 곱할까
    - 신경망을 단순하게 보면 : 입력 → Wx + b → 출력
    - x = 입력 벡터
    - W = 가중치 행렬
    - b = 편향 벡터
    - Wx + b = 새로운 정보로 변환된 벡터
        - 즉 AI가 학습한다는 것은 좋은 w와 b를 찾아가는 과정
- b ⇒ bias(바이어스)
    - AI 모델이 학습한 데이터가 특정 집단에 치우쳐 있어 **불공정하거나 편향된 결과**를 내는 현상입니다.
    - *예시:* 남성 사진으로만 학습한 얼굴 인식 AI가 여성 얼굴을 잘 인식하지 못하는 경우.

## 베이즈 정리

### 베이즈 정리 = “결과로부터 원인을 추론하는 방법”

### AI = “데이터로부터 가장 그럴듯한 답을 추론하는 시스템”

### 예시

| 수식 | 의미 | 스팸 메일 AI에서 |
| --- | --- | --- |
| A | 우리가 알고싶은 사건 | 메일이 스팸이다 |
| B | 새롭게 관찰한 증거 | 메일에 ‘무료’라는 단어가 있다 |
| P(A) | 사전확률 | 전체 메일 중 스팸일 확률 |
| P(B|A) | 조건부확률 | 스팸 메일에 ‘무료’가 등장할 확률 |
| P(B) | 증거가 나타날 전체 확률 | 전체 메일에서 ‘무료’가 등장할 확률 |
| P(A|B) | 사후 확률 | ‘무료’가 포함된 메일이 스팸일 확률 |

## 선형회귀(예측 함수)

### “입력값을 이용해서 숫자로 된 결과를 예측하는 방법”

- y = wx + b
    - 예시
        
        시험점수 = 10 x 공부시간  + 30
        
        | 공부시간 | 예측점수 |
        | --- | --- |
        | 1시간 | 40점 |
        | 2시간 | 50점 |
        | 3시간 | 60점 |
        | 4시간 | 70점 |
- b가 필요한 이유
    - b가 없으면 x=0일 때 y는 무조건 0이 됩니다.
    - 즉, 모든 모델의 직선/평면이 **반드시 원점만을 지나도록 강제**됩니다.
    - b가 없을 경우 기울기 w를 아무리 조절해도 데이터를 올바르게 지나가는 직선을 만들 수 없습니다.
- 그런데 실무에서는 입력이 하나가 아니다
    - 실제 문제에서는 공부시간 하나만 가지고 점수를 예측하지 않는다
    - 예를 들어
        - 공부시간
        - 출석률
        - 과제점수
        - 이전 시험 점수
    - 등을 같이 사용
    - $$y = w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + b $$
    - $$hw(x) = w^tx + b $$
- 중요한것은 “예측”보다 “학습”

## 비용함수 - MSE(평균 제곱 오차)

선형 회귀 = 예측하는 방법

MSE = 그 예측이 얼마나 틀렸는지 측정하는 방법

- MSE = 처음부터 끝까지 (실제 점수 - AI예측)후 제곱을 하고 더하여 개수만큼 나눈다
- y^ ⇒ 예측값을 의미한다

- Gradient(경사)
    - 현재 위치에서 MSE를 줄이려면 w와 b를 어느 방향으로 움직여야 하는가?
    - 그 방향을 알려주는것
    - 반대 방향으로 이동하면 된다
- **기울기(Gradient)의 의미**
    - 미분을 통해 구한 기울기는 "함숫값이 가장 가파르게 증가하는 방향"을 가리킵니다.
    - 즉, 기울기 방향으로 움직이면 손실(Loss/Cost)이 더 커집니다.
- **반대 방향(−기울기)으로 가야 하는 이유**
    - 모델 학습의 목표는 오차/손실(Loss)을 최소화(0에 가깝게)하는 것입니다.
    - 손실을 줄이려면 가장 가파르게 감소하는 방향으로 내려가야 하며, 그 방향이 바로 기울기의 반대 방향(−∇f)입니다.

## ReLU 함수

### “**Rectified Linear Unit**의 약자로, 신경망에서 사용하는 **활성화 함수”**

- ReLU(x) = max(0, x)
- x의 값에 따른 결과
    - x ≤ 0 ⇒ x의 값이 0 이하일 경우 모두 0의 결과값이 나온다
    - x ≥ 0 ⇒ x의 값이 0 이상일 경우 형태 그대로 결과값이 나온다
- 신경망에서 왜 필요할까?
    - **단순 직선 계산만 하는 신경망에 '꺾임(비선형성)'을 주어 복잡한 데이터를 분류할 수 있게 만드는 역할**
    - 복잡한 현실 데이터(곡선, 이미지, 텍스트 패턴 등)를 학습하려면 비선형 함수인 **ReLU**가 필수적
    - **빠른 연산**: 단순 0 비교 연산만 수행하므로 계산 속도가 매우 빠르다
    - **기울기 소실(Vanishing Gradient) 완화**: 양수 영역에서는 미분값이 항상 1로 유지되어 딥러닝 모델 학습이 안정적
- 계층적 특징 추출
    - 신경망은 한 번에 정답을 맞히는 게 아니라, 층(Layer)을 거치며 **선/점 같은 단순한 특징부터 얼굴/형체 같은 복잡한 특징**으로 단계별로 조합하며 인식합니다.
- **ReLU의 스위치 역할 (Feature Filtering)**
    - 특징 있음 (z>0): 값 그대로 전달 (ReLU(3.7)=3.7) → 신호 활성화
    - 특징 없음 (z≤0): 0으로 차단 (ReLU(−2.1)=0) → 불필요한 정보 제거
- 희소성 확보
    - 필요 없는 특징(음수값)을 전부 0으로 만들어 버림으로써, 정말 중요한 특징 신호만 다음 뉴런으로 전달하여 연산 효율을 높입니다.

## 층(Layer)

### “ 입력된 데이터를 다음 단계로 전달하며 **특징을 추출하고 학습하는 계산 단계를 의미하는 기본 단위”**

- 사람의 뇌가 여러 신경세포(뉴런)들이 연결되어 정보를 처리하듯, 인공신경망도 여러 층을 쌓아서 입력 데이터를 처리한다

| 구분 | 역할 | 비유(공장라인) |
| --- | --- | --- |
| 입력층 | 외부 데이터를 받아오는 첫번째 단계 | 원재료를 받아오는 수하물 반입구 |
| 은닉충 | 데이터에서 중요한 특징을 추출하는 중간 단계 | 부품을 조립하고 정제하는 중간 작업자들 |
| 출력층 | 최종 예측 결과(클래스 확률 등)를 만드는 마지막 단계 | 완제품을 최종 포장해서 내보내는 출하구 |
- 예시
    
    사진 속 동물이 '강아지'인지 '고양이'인지 맞히는 모델을 만든다고 가정
    
    - **입력층:** 사진의 **픽셀 데이터**(숫자 정보)를 그대로 받아들입니다.
    - **은닉층 1:** 선, 점, 곡선 같은 **아주 단순한 모양**을 감지합니다.
    - **은닉층 2:** 선들을 조합해 **귀, 눈, 코의 형태**를 알아챕니다.
    - **은닉층 3:** 얼굴 전체 형태를 조합해 **강아지나 고양이의 전체적인 특징**을 만듭니다. (앞서 배운 **ReLU** 같은 활성화 함수가 이 은닉층들에서 복잡한 특징을 파악하도록 돕습니다.)
    - **출력층:** 최종 계산된 특징을 바탕으로 "강아지일 확률 90%"라는 최종 답을 냅니다. (이때 **시그모이드**나 **소프트맥스** 함수가 쓰입니다.)
- 데이터가 여러 '층'을 지나갈수록 점진적으로 고차원적인 특징을 이해하게 되며, 층을 여러 개 깊게 쌓아서 학습시키는 기술을 딥러닝이라고 한다
