# 1차시

## 스칼라, 벡터, 행렬

### “현실의 데이터와 신경망의 계산을 숫자로 표현, 그 숫자들을 효율적으로 계산하기 위해서 필요하다.”

- 개념
    - Ai에서 하는 역할
- 스칼라
    - 하나의 값을 나타낼때 사용
- 벡터
    - 데이터를 여러 숫자를 한꺼번에 표현
    - 숫자를 여러개로 묶은 것
    - Ai에서는 특히 데이터의 특징, 단어의 의미를 표현할때 중요
    - 현실의 복잡한 정보를 숫자 여러개로 바꿔놓은것
- 행렬
    - 벡터를 변환하는 강력한 도구
    - 숫자를 가로 x 세로로 묶은 것
    - AI에서 행렬이 중요한 이유는 신경망의 계산 대부분이 행렬 연산으로 이루어지기 때문
- 텐서
    - 행렬을 여러 차원으로 확장
- Ai는 왜 행렬을 계속 곱할까
    - 신경망을 단순하게 보면 : 입력 → Wx + b → 출력
    - x = 입력 벡터
    - W = 가중치 행렬
    - b = 편향 벡터
    - Wx + b = 새로운 정보로 변환된 벡터
        - 즉 AI가 학습한다는 것은 좋은 w와 b를 찾아가는 과정
- b ⇒ bias(바이어스)
    - AI 모델이 학습한 데이터가 특정 집단에 치우쳐 있어 **불공정하거나 편향된 결과**를 내는 현상입니다.
    - *예시:* 남성 사진으로만 학습한 얼굴 인식 AI가 여성 얼굴을 잘 인식하지 못하는 경우.

## 베이즈 정리

### 베이즈 정리 = “결과로부터 원인을 추론하는 방법”

### AI = “데이터로부터 가장 그럴듯한 답을 추론하는 시스템”

### 예시

| 수식 | 의미 | 스팸 메일 AI에서 |
| --- | --- | --- |
| A | 우리가 알고싶은 사건 | 메일이 스팸이다 |
| B | 새롭게 관찰한 증거 | 메일에 ‘무료’라는 단어가 있다 |
| P(A) | 사전확률 | 전체 메일 중 스팸일 확률 |
| P(B|A) | 조건부확률 | 스팸 메일에 ‘무료’가 등장할 확률 |
| P(B) | 증거가 나타날 전체 확률 | 전체 메일에서 ‘무료’가 등장할 확률 |
| P(A|B) | 사후 확률 | ‘무료’가 포함된 메일이 스팸일 확률 |

## 선형회귀(예측 함수)

### “입력값을 이용해서 숫자로 된 결과를 예측하는 방법”

- y = wx + b
    - 예시
        
        시험점수 = 10 x 공부시간  + 30
        
        | 공부시간 | 예측점수 |
        | --- | --- |
        | 1시간 | 40점 |
        | 2시간 | 50점 |
        | 3시간 | 60점 |
        | 4시간 | 70점 |
- 그런데 실무에서는 입력이 하나가 아니다
    - 실제 문제에서는 공부시간 하나만 가지고 점수를 예측하지 않는다
    - 예를 들어
        - 공부시간
        - 출석률
        - 과제점수
        - 이전 시험 점수
    - 등을 같이 사용
    - $$y = w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + b $$
    - $$hw(x) = w^tx + b $$
- 중요한것은 “예측”보다 “학습”

### 비용함수 - MSE(평균 제곱 오차)

선형 회귀 = 예측하는 방법

MSE = 그 예측이 얼마나 틀렸는지 측정하는 방법

- MSE = 처음부터 끝까지 (실제 점수 - AI예측)후 제곱을 하고 더하여 개수만큼 나눈다

## 경사 하강법

### MSE를 가장작게 만드는 W와 b를 찾아가는 방법

- 예측함수 → MSE계산 → MSE를 줄이기 위해 w, b 수정
    - 예시
        - 등산한다고 가정 → 눈을 감고 가장 낮은 곳으로 가야한다
        - 현재 위치에서 주변의 경사를 느껴보니 “이쪽으로 내려가는게 가장 가파르겠는데?” 라고 판단
        - 그러면 그 방향으로 조금 이동 → 그리고 다시 주변 확인

- Gradient(경사)
    - 현재 위치에서 MSE를 줄이려면 w와 b를 어느 방향으로 움직여야 하는가?

- 수식

    - w : AI가 학습해야 하는 가중치
    - b : AI가 학습해야하는 편향
    - j : 비용 함수, 여기서는 보통 MSE
    - **α : 학습률**
    - w를 바꿨을때 MSE가 어떻게 변하는가?
        - 기울기가 양수일때 : w를 늘리면 MSE 증가(상승)
            - 오차가 늘어나므로 w를 줄여야 한다
        - 기울기가 음수일때 : w를 늘리면 MSE가 감소(하강)
            - 오차가 줄어들므로 w를 더 늘려야 한다
        - 기울기가 0일때 : w를 조금 바꿔도 MSE변화가 없다(최적 상태)
            - 오차가 가장 적은 최적의 지점에 도달한 상태
