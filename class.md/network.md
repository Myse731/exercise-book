# 터미널 명령어

```python
ubuntu@raspberrypi:~$
```

- ubuntu — 지금 로그인한 계정
- rasepberrypi — 이 컴퓨터(호스트)의 이름
- ~ — 지금 내가 있는 위치(~는 “내 홈 폴더” 라는 뜻)
- **$** — 일반 사용자로 로그인했다는 표시 (관리자 권한으로 들어가면 #으로 바뀜)

## 기본 탐색·파일 관리 명령어

| 명령어 | 설명 | 예시 |
| --- | --- | --- |
| `pwd` | 현재 위치(경로) 출력 | `pwd` |
| `ls`, `ls -al` | 현재 폴더의 파일 목록 (`-al`: 숨김파일까지 자세히) | `ls -al` |
| `cd` | 폴더 이동 (`cd ..`: 상위 폴더, `cd ~`: 홈으로) | `cd network_project` |
| `mkdir` | 새 폴더 만들기 | `mkdir project` |
| `touch` | 빈 파일 만들기 | `touch hello.txt` |
| `cp` | 복사 | `cp hello.txt hello_backup.txt` |
| `mv` | 이동(이름 변경 포함) | `mv hello.txt hello_backup.txt` |
| `rm`, `rm -r` | 파일 삭제, 폴더 통째로 삭제(`-r`, 비어있지 않아도 삭제됨) | `rm -r old_test` |
| `cat` | 파일 내용을 터미널에 그대로 출력 | `cat hello.txt` |
- pwd, cd, mkdir로 하는 일은 결국 아래와 같은 폴더 나무 위에서 위치를 옮기고 새 가지를 만드는 것과 같음

```python
/ (루트)

|

home

|

내 계정

|

폴더
pwd로 지금 내 위치를, cd로 이동을, mkdir로 새 폴더를 만드는 것
 => 이 트리위에서 움직이는것과 같다.
```

## vi 편집기

```python
vi 파일명.txt(.py 등등)
```

#### 문자 입력 모드로 들어가는 키

| 키 | 동작 |
| --- | --- |
| `i` | 현재 커서 앞에서부터 입력 시작 |
| `a` | 현재 커서 뒤에서부터 입력 시작 |
| `o` | 현재 줄 아래에 새 줄을 만들고 입력 시작 |
| `O` | 현재 줄 위에 새 줄을 만들고 입력 시작 |
| `r` | 커서 위치의 글자 하나만 덮어쓰기 |

#### 저장과 종료(명령 모드에서 입력)

| 명령 | 동작 |
| --- | --- |
| `Esc` | 입력 모드 → 명령 모드로 복귀 (저장/종료 전에 항상 먼저 누름) |
| `:wq!` | 파일을 저장하고 종료 |
| `:q!` | 저장하지 않고 종료 |

```python
:set nu를 명령 모드에서 입력하면 줄 번호가 표시됨.
나중에 코드 몇 번째 줄에 에러가 났는지 확인할 때 유용함
```

## 관리자 권한과 프로세스 확인, 종료

#### 리눅스는 여러 사용자가 함께 쓰는 것을 가정하기 때문에 시스템에 영향을 주는 작업은 아무나 할 수 없게 막아둠

**sudo**는 ‘지금 이 한 줄만 관리자 권한으로 실행해달라’는 명령

**chmod**는 파일 자체에 ‘누가 실행할 수 있는지’ 권한을 지정하는 명령

| 명령어 | 설명 | 예시 |
| --- | --- | --- |
| `sudo` | 다음 명령을 관리자 권한으로 실행 | `sudo apt update` |
| `chmod +x` | 파일에 실행 권한 추가 | `chmod +x run.sh` |
| `sudo apt install` | 시스템 프로그램 설치 | `sudo apt install <패키지명>` |
| `sudo pip3 install` | 파이썬 라이브러리 설치 | `sudo pip3 install <패키지명>` |

| 명령어 | 설명 | 예시 |
| --- | --- | --- |
| `ps -ef` | 지금 실행 중인 프로세스 전체 목록 | `ps -ef |
| `sudo kill -9 PID` | 지정한 PID(프로세스 번호)를 강제 종료 | `sudo kill -9 1234` |
